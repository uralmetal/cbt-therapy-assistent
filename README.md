# КПТ Ассистент

Учебный проект дневника СМЭР. Русскоязычный пользователь описывает эпизод в Telegram, сам формулирует ситуацию, мысли, эмоции и реакции и подтверждает показанную карточку перед сохранением. Для MVP выбран последовательный UX‑A с коротким маршрутом для уже заполненной карточки.

UX‑A проверен в ChatGPT. В `prototypes/api` находится стартовый скелет для разработки локального Telegram/Gemini-прототипа. Статус условий для MVP указан в [архитектурной проверке готовности](docs/architecture/architecture-readiness.md).
