## Требования

R1 — Python + фактическое внешнее API, проверяемый код и воспроизводимый запуск. R2 — один эпизод и одна активная запись, следующая по отдельной просьбе после завершения. R3 — пользовательское авторство, нейтральная помощь, спорное отдельно, не диагноз. R4 — частичность при определённом эпизоде, явное подтверждение показанной версии, правка/пропуск, подтверждённая отмена. R5 — фактическое сохранение, успех после операции, повтор без дубликата, остановка упражнения при явной угрозе. R6 — синтетические публичные материалы и ограничения приватности/безопасности, без клинической гарантии. R7 — ручные тесты ключевых сценариев с доказательствами, проверяемость кода. R8 — 07.12.2026, Jupyter не обязателен, стенд желателен. R9 — H-01–05 и варианты A/B/C остаются гипотезами. R1/R2/R7/R8 основаны на постановке заказчика; R3–R6 — текущие общие правила Discovery, не утверждение UX. [Issue #1](https://github.com/uralmetal/cbt-therapy-assistent/issues/1), [Discovery Brief](https://github.com/uralmetal/cbt-therapy-assistent/blob/fb43439ccfa0a88e5128e397326ed77abc91d2b4/docs/product/product-brief.md), [UX](https://github.com/uralmetal/cbt-therapy-assistent/blob/fb43439ccfa0a88e5128e397326ed77abc91d2b4/docs/product/hypotheses-and-options.md), [Validation](https://github.com/uralmetal/cbt-therapy-assistent/blob/fb43439ccfa0a88e5128e397326ed77abc91d2b4/docs/product/validation.md), [требования заказчика](https://github.com/uralmetal/cbt-therapy-assistent/pull/3#issuecomment-7126194705).

R10 — **строго stateless Python, никакого локального пользовательского хранилища** (C-01/C-04). R11 — Python приложение на **Render** (C-01/C-05). R12 — ожидаемая нагрузка до 10 пользователей и меньше 1 входящего запроса/с (C-01/C-06), не согласованные суточные квоты/доступность/latency. R13 — внешнее LLM API с бесплатным стартом и достаточным контекстом (C-06). R14 — простота внешнего хранилища и возможность независимой аналитики (C-04); по C-14 аналитический контур не входит в схему/текущий MVP, возможное развитие отложено. R15 — на старте не планируются чувствительные сведения и пользователи ЕЭЗ/CH/UK (C-13); для Gemini Free — закрытая синтетика, без личного/конфиденциального ввода, проверка возраста и допустимых регионов/условий. Реальные данные не согласованы.

## Открытые решения и действия

- Q08: выбрать UX после фактических тестов и зафиксировать в #1; Telegram принят, голос отдельно.
- Q09: подтвердить закрытый синтетический учебный профиль с авторизованными взрослыми участниками в допустимых регионах, без чувствительных/персональных/конфиденциальных текстов, сроки удаления/хранения и политику остановки. Не расширять на личный дневник. Аналитика не входит в текущий MVP.
- Q07/Q11: Gemini и Supabase выбраны как поставщики/направление; модель Flash-Lite, free аккаунты/квоты и регион, доступ из Render, synthetic smoke-test и параметры подключения проверить. Render Postgres — опция отдельного stage/demo; проверить срок Free и изоляцию при использовании.
- После повторного независимого ревью и снятия Q08/Q09, подтверждения модели/условий и технических проверок — пересмотреть Gate. Принятие шести ADR не означает готовности реализации. AR-06 OPEN.
